# Cafe-demo

A premium, minimalist specialty café website built for **KŌVA — Specialty Coffee Roasters & Kitchen** (Panampilly Nagar, Kochi, Kerala).

Designed and developed by [Redix Media](https://redix.in).

## Features

- **Scandinavian Minimalism & Editorial Aesthetics**: Warm ivory, soft cream, dark espresso, and muted olive palette paired with refined typography (*Cormorant Garamond* and *Plus Jakarta Sans*).
- **Navigation**: Sticky bar with subtle backdrop blur, quick directory links, and mobile slide-down menu.
- **Hero Section**: Asymmetrical editorial layout with rich specialty coffee imagery, quick origin metrics, and direct calls to action.
- **Philosophy**: Direct-trade single-origin shade-grown Arabicas from Wayanad and Chikmagalur, natural processing, and craft roasting.
- **Signature Menu**: Curated preview of 6 signature items with realistic Kerala café pricing in Indian Rupees (₹), dietary tags, and an interactive **Full Menu Modal**.
- **Signature Experience**: Atmosphere showcase highlighting tactile materials, analog vinyl soundscape, natural lighting, and relaxed seating.
- **Visual Photo Journal**: Asymmetrical gallery grid with category filtering and an interactive full-screen **Lightbox Modal**.
- **Our Story**: The origin journey of two founders bringing high-elevation shade-grown Indian coffee back home to an urban Kerala sanctuary.
- **Visit Us**: Fictional address in Panampilly Nagar, Kochi, day-by-day opening hours, demo telephone, Google Maps directions, and an architectural styled map card.
- **Table Reservation**: Complete reservation & enquiry form with validation, loading animation, and realistic confirmation flow.
- **Footer**: Full site directory, hours, location, Instagram, Atelier Radio, and discreet Redix Media watermark.

## Tech Stack

- **React 19**
- **Vite 8**
- **Tailwind CSS v4**
- **Lucide Icons**

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
